# Parmana Verifier

The Parmana verifier checks Parmana proofs offline. It is intended to let anyone confirm a proof without contacting Parmana's services.

**Status: scaffold only.** This folder does not yet contain verifier code. The verifier is being written fresh from the proof-format specification and is held until the signing and verification logic it depends on has been reviewed. No installation or usage commands are documented because none have been run against this folder.

## Installation and usage
