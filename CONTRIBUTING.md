# Contributing

**INCOMPLETE:** this document is a draft pending legal review.

## Reporting issues

Open an issue in this repository. Include the proof or input you used, the expected result, and the actual result. Do not include real secrets, keys, or customer data.

## Submitting changes

1. Fork the repository and create a branch for your change.
2. Make the change and include tests for it.
3. Open a pull request describing what changed and why.

Contributions are accepted only after the contributor signs the Contributor License Agreement.
